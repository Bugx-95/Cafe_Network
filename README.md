# ☕ Cafe_Network

Welcome to **Cafe_Network**, a friendly command-line bot that manages a cafe's greeting and ordering sequence. 

### 📅 The Backstory
This is a very special repository because it contains the **first Python project** I ever created back in 2022! It was the moment I followed the advice:

> *"You can't learn unless you start to build something."*

I took those words to heart and built **Mack**. While the logic is simple, Mack represents the foundation of my programming journey and the start of my coding inventory.

---

### 🛠️ Features
* **Interactive Dialogue:** A scripted sequence to welcome customers.
* **Ordering System:** Takes user input to simulate a real cafe experience.
* **Math Logic:** Handles basic calculations for the orders.
* **Nostalgic Code:** Kept in its original form to show where I started!

### 💡 What I Learned
* Handling user input and strings.
* Basic mathematical operations in Python.
* The importance of starting small to learn big.
